# 温州医科大学 · 2026 校园黑客松 宣传片（HTML）

纯前端 HTML 动画宣传片，1920×1080 / 30 秒，单页 `index.html` + GSAP 时间轴驱动，无需构建、无需后端。

## 运行

直接用浏览器打开 `index.html` 即可（建议 Chrome / Edge，窗口或全屏按 16:9 显示）。
若需 HTTP 方式预览：

```powershell
python -m http.server 8080
# 打开 http://127.0.0.1:8080/
```
