0 · 总则：先把入口和「读数心法」打通

所有外文库都从学校 WebVPN 进；PubMed 免费，不用 VPN。下面先立规矩，后面每个库都照着做。

通用心法（每题都适用）
  1. 浏览器开 https://webvpn.wmu.edu.cn，统一身份认证登录。
  2. 首页卡片进库：中国知网 / 万方数字化期刊 / 中国生物医学文献数据库(CBM) / SCI数据库1(webofscience.clarivate.cn) / Scopus。点了会新标签页，URL 变成 https://webvpn.wmu.edu.cn/https/7772647…，这段 token 不要手改。
  3. 认机构成功：WOS 右上角 “Wenzhou Medical College”；万方顶部「温州医科大学」；Scopus 顶部 “Wenzhou Medical University”；知网右上角「温州医科大学」。
  4. 字段靠下拉选，不靠手写：知网、CBM、万方、WOS、PubMed 的高级检索都是「每行一个字段下拉 + 一个词框」。先在下拉里点字段，再在框里填光秃秃的词，再按回车。你在结果页看到的 [Title]、主题：、（X：Y） 是系统自己拼给你看的，不要反过来把它们敲进框里。
  5. 读数只看「命中总数」：知网看「共找到 N 条结果」；万方看「共 N 条」；CBM 看左栏 navstat + 「共X页」；WOS 看 “N Documents”；PubMed 看 “N results”。不要拿翻页数×每页条数去猜（有余数会错）。分面签上的小数字别当命中总数——比如知网总库查得 94 条，左边分类签写着「学位论文 26」，26 是那个专场里的条数，不是这次检索的总数。
  6. 题里每一个限定词都要落到检索式或筛选上：年代(2021-2026)、文献类型(综述/期刊/会议/学位论文)、核心期刊、SCI收录、年龄段(65岁以上)。漏一个，数字就会大很多。
  7. 限定条件优先用平台自带的筛选项，不要拿关键词凑。典型例子：CBM 题面要「65 岁以上」，正确做法是展开「限定检索」勾年龄组「老年人：65岁以上」，不是多写一行「老年」当检索词——前者是年龄字段，后者是碰巧标题/摘要里出现「老年」二字，口径完全不同。

1 · CBM / SinoMed（7 题，全部实测）

入口：VPN → 图书馆--中文文献 → 中国生物医学文献数据库（CBM）。CBM 是中文医学库，四类检索：快速、高级、主题、分类。

CBM 通用操作（先看这 6 条，题题都用到）
  1. 快速检索：先选好检索字段下拉，输入框只填词 → 点蓝色「检索」。多个条件请用「高级检索」逐行选字段，不要手写方括号标签。
  2. 主题检索：顶部「主题检索」→ 输入词 → 选副主题词、勾「不加权/不扩展」→ 生成检索式。
  3. 分类检索：顶部「分类检索」→ 只有一个 「查找分类词」 输入框和一棵分类树，没有独立的「分类号输入框」。这个框只认类名，不认分类号：填 R541.2 会得到「已找到 0 条相关记录」，填 风湿性心脏病 才能查到 2 条（风湿性心脏病、小儿风湿性心脏病）；点类名进详情页，页头会显示 R541.2　风湿性心脏病　扩展检索，分类号在这里读。
    要真的把这一类文献检索出来：详情页的蓝色「检索」按钮提交的是空表单（会提示「请输入检索词！」），正确做法是回快速检索，字段下拉选分类号，输入 R541.2 再点检索；或者在高级检索里用分类号字段建一行。
  4. 结果页怎么读：右上「全部：N」是历史总数，不是筛选结果；真实数看左栏 navstat（如「核心期刊：119」）和底部「共X页」。
  5. 年代限定：结果页顶部「年代 [ ]-[ ]」两个框填 2021 / 2026，再点蓝色「检索」（不是点「限定检索」，那只是展开更多选项）。
  6. 年龄 / 文献类型 / 性别 / 对象，都在「限定检索」面板里勾，别当检索词写。展开「限定检索」能看到：
    · 文献类型：综述 / 讲座 / 译文 / 病例报告 / 临床试验 / 随机对照试验 / Meta分析 / 多中心研究
    · 年龄组：婴儿，新生 / 婴儿：1个月-23个月 / 儿童，学龄前 / 儿童：6岁-12岁 / 青少年：13岁-18岁 / 成年人：19岁-44岁 / 中年人：45岁-64岁 / 老年人：65岁以上 / 老年人，80岁以上
    · 性别：男(雄)性 / 女(雌)性　· 对象：人类 / 动物
    发文最多作者/机构：结果页点「学术分析」或左栏「作者/机构」看分布。

2 · 中国知网 CNKI（9 题里的知网部分）

入口：VPN → 中国知网。认机构：右上角显示「温州医科大学」。

知网通用操作（含 3 个必踩的坑，先看完再动手）
  1. 高级检索：首页搜索框右侧点「高级检索」→ 出现多行条件，每行左边下拉选字段（主题/篇关摘/关键词/篇名/全文/作者/第一作者/作者单位/文献来源/DOI…），右边填词；行与行用 AND/OR 连接 → 点「检索」。
  2. 坑 1：第二行的默认字段是「作者」，不是「主题」。如果你只填词不改字段，检索式会变成 （主题：2型糖尿病）AND（作者：遗传基因(精确)），然后返回 「抱歉，暂无数据，请稍后重试」。这个报错长得像「库里没有」，实际是字段错了。每加一行，都要先点开这一行左边的字段下拉，选中你要的字段，再填词。
  3. 坑 2：输入框的联想词下拉会盖住「检索」按钮。比如输入「胃癌」，会弹出一列「胃癌患者 / 胃癌组织 / 胃癌细胞 / 胃癌根治术…」，正好压在「检索」按钮上。此时点「检索」实际点到联想词，页面毫无反应、也不报错。
    解法：先点一下页面空白处（让输入框失焦、联想词收起），再点「检索」。不要按 Esc——Esc 可能把已经填好的词清掉。
  4. 坑 3：刷新或提交失败后，字段会回落成默认值。Ctrl+R 之后必须重新检查每一行的字段下拉，否则又回到「主题 + 作者」组合。
  5. 结果数：看顶部「共找到 N 条结果」——这才是命中总数。左上分类签上的小数字（如「学位论文 26」「学术期刊 1967」）是该专场里的条数，不是本次检索总数，别抄错。
